# Codex Skill Install Page

This folder is a static install page for `imperial-bme-codex-starter`.

## Deploy on GitHub Pages

1. Create a public GitHub repository.
2. Upload these files to the repository root:
   - `index.html`
   - `imperial-bme-codex-starter.zip`
3. Enable GitHub Pages for the repository.
4. Send the GitHub Pages URL to the student.

If the repository is hosted at:

```text
https://YOUR_GITHUB_USERNAME.github.io/YOUR_REPO/
```

the page will infer this zip URL automatically:

```text
https://raw.githubusercontent.com/YOUR_GITHUB_USERNAME/YOUR_REPO/main/imperial-bme-codex-starter.zip
```

If your default branch is not `main`, open the page with:

```text
https://YOUR_GITHUB_USERNAME.github.io/YOUR_REPO/?branch=master
```

You can also pass an explicit zip URL:

```text
https://YOUR_GITHUB_USERNAME.github.io/YOUR_REPO/?zip=https%3A%2F%2Fexample.com%2Fimperial-bme-codex-starter.zip
```
