Codex Skill Installer

安装 Imperial BME Codex Starter

这是一个给生物医学工程学生用的 Codex 入门 Skill。最简单的安装方法： 复制下面的提示词，发给 Codex，让 Agent 自己完成下载、解压和验证。

Mac 或 Windows：推荐 可以体验 Codex 本地 Agent 和 Skill。
iPad：可以先学方法 适合互动训练；本地文件工作流仍建议用电脑。

让 Agent 安装

复制提示词，发给 Codex。她不用懂命令行。

如果你把 zip 放在 GitHub 仓库根目录，地址通常像这样： https://raw.githubusercontent.com/用户名/仓库名/main/imperial-bme-codex-starter.zip

她实际要做什么

只要三步，不需要 GitHub 账号。

  1. 1
    打开这个网页 公开 GitHub Pages 页面不要求登录。
  2. 2
    复制提示词 点左边按钮即可。
  3. 3
    发给 Codex Codex 会下载、安装并告诉她下一句怎么启动。

如果她只有 iPad，可以先把提示词发给 ChatGPT/Codex 做互动训练； 如果要让 Agent 读写本地文件、生成 deck、跑代码，建议用 Mac 或 Windows 电脑。

手动安装

给懂电脑的人备用。

mkdir -p ~/.agents/skills
curl -L -o /tmp/imperial-bme-codex-starter.zip [ZIP_URL]
unzip -o /tmp/imperial-bme-codex-starter.zip -d ~/.agents/skills
